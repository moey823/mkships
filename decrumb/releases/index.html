Latest · 1.1.3 · Build 10 · September 25, 2026

Updates that explain what’s happening. Quit that stops cleaning.

  • Finish Mac updates more reliably. Fixes an installation-preparation failure that could leave Install and Relaunch stalled. App updates explains when you need to finish an action, save settings, or retry, and keeps Install and Relaunch available after a preparation failure.
  • Quit stops cleaning. Quit Decrumb now stops its background helper and closes the app. Your linked account, saved settings, queued links, and receipts stay in place. Opening Decrumb starts cleaning again.
  • Hide keeps cleaning. Choose Hide Decrumb, or close its window, to leave the helper running.

Includes the disappearing-message support, built-in rules list, and updater release notes added in 1.1.2.

Choose Check for Updates… on Mac. If an older app’s Install and Relaunch button cannot finish, follow the manual update steps. Pi users rerun the installer; Umbrel users update through its app controls.

1.1.2 · Build 9 · September 25, 2026

Clean links from disappearing messages.

  • Clean incoming links with a chat timer enabled. Disappearing messages now follow the same cleaning rules as ordinary messages. Generated notes follow Note to Self’s timer and your configured note-cleanup policy; the source chat’s timer is not copied.
  • Use phone commands with a timer. Your authenticated commands in Note to Self also work when disappearing messages are enabled. Phone commands remain optional and off by default.
  • See what gets cleaned. On Mac, open Settings → Cleaning rules → View domains and rules to see the built-in tracking parameters, extra Instagram and X/Twitter rules, exceptions, and limits.
  • Read release notes in the updater. Notes are included directly in the signed update feed, fixing the notes area’s endless loading spinner.

View-once content and spoilers remain excluded. Ordinary outgoing messages and bare links in Note to Self are still ignored, and generated notes never loop back through the cleaner.

At release, Mac Check for Updates… offered build 9. Pi users rerun the installer; Umbrel users update through its app controls. Your Signal connection and saved settings stay in place.

Mac requires Apple silicon and macOS 26.4 or later. Pi and Umbrel remain experimental; Windows remains a source-build CLI preview.

Clean X/Twitter share links.

1.1.0 · Build 7 · September 21, 2026

Decrumb, now with a Windows CLI.

Version 1.1 adds a native Windows command-line preview for technical users. All four platforms use the same Decrumb version, with matching Mac and Pi packages and a tested Umbrel image.

  • Pair from PowerShell. Scan the terminal QR, then let Decrumb clean links in the background. Control it with status, pause, and resume commands.
  • Choose login startup. Optional startup runs for your Windows user. Your PC must remain awake, online, and signed in.
  • Keep state separate. The Windows CLI protects local account files with Windows permissions and contains its helper processes so they stop together.
  • Use the same controls. Rules, previews, notes, optional phone commands, and private diagnostics are available from the CLI.

Windows is an unsigned source-build preview targeting Windows 11 on Intel/AMD 64-bit. Native tests and packaged smoke checks pass; live Signal pairing and sleep/wake acceptance remain. Pi and Umbrel remain experimental.

Mac v1 and RC6 users can choose Check for Updates… to get build 7. Pi users rerun the installer; Umbrel users update through its app controls. Existing account state and settings are preserved.

1.0.0 RC6 · September 21, 2026

Help without oversharing.

Troubleshooting now comes with a report you can inspect and share yourself. Nothing is uploaded automatically, and no telemetry service was added.

  • Preview, then copy. Find Diagnostics in the Mac app or Umbrel dashboard, or run decrumb diagnostics on Pi.
  • Useful, limited details. Reports contain versions, basic system information, local worker health, and recent error codes. Messages, links, contacts, account details, rules, activity counts, and exact event times stay out.
  • Less logging. Successful link processing no longer writes timed entries. Old rotating logs are removed when the updated app or worker starts.
  • Short local history. At most 128 error entries from seven UTC calendar days, pruned while Decrumb is active. Clear diagnostics without changing your Signal connection, settings, queue, or notes.
