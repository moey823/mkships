Decrumb · Help & support

A little help cleaning up.

Start with the answers below. For bugs or questions, use the public GitHub issue tracker.

Report an issue

Include your macOS version, app or source version, what you expected, and what happened. A made-up example link is usually enough to reproduce a cleaning problem.

GitHub issues are public. Leave out real messages, contacts, private URLs, pairing QR codes, credentials, and the app’s runtime folder. Redact personal information in screenshots.

Open GitHub issues ↗

Found a security vulnerability? Report it privately on GitHub instead of opening a public issue.

Getting started

Can I download and install the app yet?

Yes. Decrumb 1.0.0 RC1 (build 1) is a signed, notarized release candidate for installation testing on Apple silicon Macs running macOS 26.4 or newer. It includes all runtime dependencies; no Homebrew, Python, Java, or separate Signal CLI installation is needed. Download the DMG from Downloads and drag Decrumb to Applications.

What is still being tested before stable v1?

Real-device Signal linking, incoming-message delivery, note removal, and start-at-login acceptance checks remain pending. This first candidate is a prerelease for installation testing. Include the candidate version and macOS version when reporting a problem, without sharing private messages or account data.

Does Decrumb replace Signal on my phone?

No. Decrumb connects as an additional linked device. Your normal Signal app stays on your phone. Open Decrumb, choose Connect Signal, and scan the QR code from Signal → Settings → Linked Devices → Link a New Device. A fresh code can be generated if the first expires.

Where do the cleaned links go?

Only to Note to Self. Decrumb never sends an automated reply to a contact or group. Generated notes identify Decrumb, optionally include an available sender display name, and carry a searchable random code. Display names are not verified identity, and a visible code alone never authorizes deletion.

Why did a link not produce a note?

Decrumb sends only links whose eligible tracking parameters changed. It ignores messages from before its first worker startup, messages over 24 hours old, outgoing/synced messages, and Note to Self. Disappearing messages, view-once content, spoilers, edits, story replies, and unsupported privacy metadata are excluded.

Selected-site rules, exclusions, explicit keep rules, and recognized signature parameters can also leave a link unchanged. Try a synthetic example in the local preview. Exceptional bursts or ambiguous sends can still lose work; delivery is not guaranteed.

Does Decrumb need my Mac to stay awake?

Yes. Receiving and automatic cleanup require the worker running on an awake, online Mac while you are logged in. Quitting the menu bar interface leaves an active worker running. Use Pause to stop it. An optional start-at-login setting can start the interface and enabled worker when you log in.

Does Try a link send or open the link?

No. The preview applies your draft rules locally. It does not fetch, send, or save the sample. Regular cleaning also does not visit or expand URLs.

Notes and optional cleanup

Will Decrumb automatically remove my notes?

Removal is manual by default. You can set a default lifetime of 1, 6, 12, or 23 hours for new notes, or choose a periodic sweep every 1, 6, or 12 hours. Individual notes can have their own lifetime or a Keep preference.

Changing the default lifetime affects newly sent notes. It does not remove deadlines already assigned to existing notes; choose Keep on a note to cancel its deadline. Keep also excludes it from periodic sweeps. An explicit manual removal request can still include a kept note.

Which notes can Decrumb remove?

Only eligible notes for which this installation recorded an acknowledged send, bound to the same linked account. It does not search your conversation for matching words, links, sender names, or Decrumb codes. Personal notes and notes without a trustworthy local receipt are not cleanup targets.

Older notes, ambiguous sends, or lost receipt metadata may require manual removal in Signal.

Does “Removal requested” mean a note is gone everywhere?

No. It means Signal CLI acknowledged a removal request. Signal’s supported delete-for-everyone window is 24 hours, and removal is best effort. Decrumb stops requests shortly before that limit to allow dispatch time.

A deleted-message marker may remain. Removal does not promise erasure from every device, quotes, saved copies, or backups. Deleting or editing the original incoming message does not retract a generated note.

What happens if my Mac sleeps or I pause cleaning?

Automatic cleanup also pauses. Sleeping, offline, or paused time can cause a note to miss the supported removal window. The app reports an old or unconfirmed request instead of treating it as successful.

An explicit manual removal action while paused attempts up to three requests. More can remain queued; repeat the action or resume the worker to continue. The action does not silently enable incoming-message processing.

What does Clear queued links do?

It discards local, unattempted notes without removing anything already sent to Signal. Pause normally preserves valid queued notes; Discard queued links on pause is optional and off by default. Saving cleaning-rule changes clears pending links made under the previous rules.

Privacy and access

Where does the app keep its local data?

Signal keys and state, configuration, temporary pairing images, the plaintext outbox, and content-free receipt metadata are stored in the app’s protected runtime directory. Permissions restrict access but do not encrypt the folder. Read the privacy policy before linking an account.

How do I revoke access to my Signal account?

In Signal on your phone, open Linked Devices and unlink Decrumb’s device. Pause or stop the local worker too. Unlinking does not promise deletion of local files or notes already delivered to your other devices. Do not remove another linked device by mistake.

Is this an official Signal app?

No. Decrumb is an independent, unofficial open-source utility using the unofficial signal-cli client. It is not affiliated with or endorsed by Signal. Service changes may require updates.
