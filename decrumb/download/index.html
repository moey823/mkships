Decrumb for Mac, Raspberry Pi, Umbrel, and Windows

Get Decrumb.

Clean the links you receive on Signal and save them to Note to Self automatically.

One Decrumb version across all four platforms: 1.1.3. Windows is an experimental CLI preview for technical users.

Version 1.1.3

Free for Apple silicon Macs.

Requires macOS 26.4 or later. Signed app, notarized by Apple. Everything you need is included.

Install it on a Mac you leave awake and online. An always-on Mac mini is a good fit. Decrumb stops cleaning when that Mac sleeps, goes offline, or shuts down.

Download for Mac · 67.4 MB

See what’s new in v1.1.3 →

Set up the Mac app.

  1. Install Decrumb. Open the download and drag Decrumb into Applications.
  2. Connect Signal. Open Decrumb and choose Connect Signal. On your phone, go to Signal → Settings → Linked Devices → Link a New Device, then scan the QR code.
  3. Find your clean links. Cleaning starts automatically after connecting. Open Note to Self in Signal to find the results.

You’ll need an existing Signal account. Keep the Mac awake, online, and logged in, with cleaning enabled. Its screen can be off. Intel Macs aren’t supported.

Raspberry Pi.

Version 1.1.3 · Command line

For Raspberry Pi OS 64-bit, Bookworm or later. Runs in the background, with QR pairing in your terminal over SSH. No desktop or monitor needed.

Keep the Pi powered on and online. Install as your normal user, scan the QR code from Signal on your phone, and enable startup at boot.

Uses Python 3.11+ and qrencode. The installer downloads a separate, checksum-verified ARM64 Signal client from a community provider linked by signal-cli. ARM Linux checks pass; physical Pi and live Signal acceptance testing remain.

Umbrel.

Version 1.1.3 · Experimental community app · ARM64 and Intel/AMD 64-bit

Run Decrumb on your always-on home server. Connect Signal, change rules, and check the helper from your browser. No terminal needed for normal setup.

  1. Add the community store. In Umbrel’s App Store, add https://github.com/moey823/decrumb as a community app store.
  2. Install and open Decrumb. Unlock it with the app password shown in Umbrel’s app details. Let the Signal helper finish downloading.
  3. Scan the QR code. In Signal on your phone, open Settings → Linked devices → Link a new device. Cleaning starts after linking.

If Decrumb already runs on another machine, pause that copy to avoid duplicate notes. Keep Umbrel online and allow at least 1 GB of free disk space for setup.

Umbrel setup guide ↗

Both container architectures pass automated tests, and live Umbrel testing has been confirmed. This is a community package, not an official Umbrel App Store listing.

Windows CLI preview.

Version 1.1.3 · Build 10 · Experimental

A native command-line edition for technical users on Windows 11, Intel/AMD 64-bit. Pair in PowerShell, then keep cleaning in the background. Windows on ARM has not been validated.

This edition is currently available to build from source. The resulting bundle includes Python, Java, and the Signal client; it runs without WSL, Docker, or administrator rights. Building it requires Python 3.13 and the dependencies in the guide.

Build and setup instructions ↗
  1. Build and extract the complete bundle. Keep its helper and runtime folders together in their final location.
  2. Connect Signal. In PowerShell, run .\decrumb.exe setup and scan the terminal QR from Signal’s Linked devices screen.
  3. Control the helper. Use .\decrumb.exe status, pause, or resume. Login startup is optional: .\decrumb.exe start-at-login enable.

Keep the PC awake, online, and signed in. You can close PowerShell after setup. Pause persists through restart; resume starts the background helper again.

Native Windows tests and packaged dependency checks pass. Builds are unsigned; a signed public Windows download, live Signal pairing, and sleep/wake acceptance are still pending. Pause any Decrumb instance on another machine before switching.

Already have Decrumb on Mac?

On Mac, choose Check for Updates… in the app. Automatic updates are optional and off by default. Version 1.1.3 is build 10. It improves update installation and retry messages, and makes Quit Decrumb stop cleaning. Use Hide Decrumb to leave cleaning running. Your Signal connection and saved settings stay in place.

Updater stuck, or updating from RC1?

If you enabled Discard queued links on pause, turn it off first to keep pending links.

Pause cleaning and confirm it shows Paused. Quit Decrumb. If an older version’s stuck updater prevents quitting, use macOS Force Quit after cleaning is paused. Let any pending installation finish, then download this version, drag it into Applications, and choose Replace. Open Decrumb. Cleaning starts automatically. Your Signal connection and saved settings stay in place.

Use these steps if an older version’s Install and Relaunch button does not finish the update. RC1 also needs this manual update once; future updates can happen in the app.
