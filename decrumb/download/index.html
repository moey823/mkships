Current build requirements

  • An Apple silicon Mac.
  • Apple command-line development tools and Python 3.13 or newer.
  • The packaged developer build is currently validated on macOS 27.0 only. Compatibility with older macOS versions or Intel Macs is not established.

The build packages the local worker, URL cleaner, and pinned unofficial Signal CLI. A source build needs development tools; it is not an installer.

Read the build and validation instructions →

What is available now?

The source code, documentation, and offline tests are public under AGPL-3.0-only. There is currently no public DMG, notarized app download, or automatic update feed.

Development builds are ad-hoc signed by default. Signing, notarization, compatibility testing, and distribution materials remain part of preparing the public app.
