Poker night, on your own server.

Felt Night is a mobile-friendly Texas Hold’em tournament app for private groups. Host tables, play with chips that have no cash value, and keep the game data on the server you run.

Built for the whole table

A tournament that stays in your hands.

Run a private game for your group, with the server keeping the hand in order and each player seeing the table from their own seat.

01 · HOST

Shape the tournament.

Open multiple tables with 2–9 seats each. Before play, the host can set starting stacks, blinds, blind-level length, shot clock, all-in delay, buy-in and payout split.

02 · PLAY

Keep the table in view.

The browser layout works on phones and larger screens. The table stays oriented around your seat, with actions beside your hole cards.

03 · DEAL

Let the server run the hand.

The server checks turns and legal actions, keeps hidden cards private, and settles ties and side pots. Players can review available hand records after a tournament.

04 · ACCOUNT

Keep your own history.

Players sign in with individual accounts. Their history shows tournament results and the hand records available for those games.

From a phone or desktop

Every player gets their own seat.

The table stays oriented around your seat, with your actions beside your hole cards. The layout adapts as you move between phone and desktop screens.

♠

Play chips only

A private game, without cash play.

Felt Night has no deposits, cash-outs, prizes or rebuys. Betting chips and tournament buy-in credits stay inside the game and have no cash value.

Your server, your room

Run Felt Night yourself.

The app uses Python’s standard library and SQLite. It needs Python 3.9 or newer and an HTTPS reverse proxy in front of the loopback web process.

Start with the source.

  1. Clone the Felt Night repository.
  2. Choose a persistent data directory outside the checkout.
  3. Point your HTTPS proxy to 127.0.0.1:18943 and set the exact public origin.

Registration requires the room invite password you configure for your group. Players then use their own username and password.

Read the setup notes on GitHub ↗
TerminalPython 3.9+
git clone https://github.com/moey823/felt-night.git
cd felt-night
python3 server.py \
  --host 127.0.0.1 \
  --port 18943 \
  --public-origin https://poker.example.com \
  --data-dir "$HOME/.local/share/felt-night"

Fair play, clearly described

The deal stays on the server.

A fresh deck is shuffled with Python’s random.SystemRandom, which draws randomness from the operating system. The deck and hidden cards stay server-side; the browser receives only the cards that player is allowed to see.

Know the limits.

The server validates actions and controls the deal, but this is not a cheat-proof or independently certified poker room. There is no public shuffle proof, and the person running the server controls its code and data. Use it for private play-chip games.
